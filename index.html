AU / WO / US / EP bulk processor
A staged bulk tab that checks for WO, US and EP publication numbers using the same family biblio logic as the family bulk tab, then filters those family publications into adjacent office columns.
Or paste application numbers, one per line, and run without an Excel file.
Manual entry list
AU / WO / US / EP behaviour
• API credentials are embedded in this build and the API panel is hidden
• Uses family biblio first, then filters family publication numbers to AU, WO, US and EP only
• For US and EP, publications ending with a bare W, P, A, S, F or D are excluded from every tab and bulk result. For AU, publications ending with % or a bare A are excluded from every tab and bulk result
• Output workbook columns are pams_application_number, au_publications, wo_publications, us_publications and ep_publications
• Multiple publications inside the same office column are separated with line breaks inside the cell
• The preview shows the current batch only, then switches to the next batch when the next batch starts
• Queries are staged in batches of 100, then the tool pauses for 2 minutes before starting the next batch
